# Triage labels

| Role                                | Label             |
| ----------------------------------- | ----------------- |
| Unreviewed                          | `needs-triage`    |
| Waiting for more context            | `needs-info`      |
| Ready for autonomous implementation | `ready-for-agent` |
| Requires human judgment             | `ready-for-human` |
| Intentionally declined              | `wontfix`         |
