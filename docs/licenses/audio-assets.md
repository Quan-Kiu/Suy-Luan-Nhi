# Bundled audio assets

All currently bundled sound effects come from Kenney asset packs and are licensed under Creative Commons CC0 1.0.

Official sources:

- Interface Sounds: `https://kenney.nl/assets/interface-sounds`
- Music Jingles: `https://kenney.nl/assets/music-jingles`
- Kenney support and licensing: `https://kenney.nl/support`

Attribution is not required, but source metadata is retained for traceability.
