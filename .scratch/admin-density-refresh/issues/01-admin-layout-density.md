# Compact admin records and internal scrolling

**Status:** ready-for-human

- Added independent inline scrolling for the desktop sidebar and main workspace.
- Replaced always-expanded repeated forms with compact expandable records.
- Reduced card padding, preview height, action height, and unused whitespace.
