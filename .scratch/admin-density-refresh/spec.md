# Admin layout density refresh

## Objective

Reduce the space used by repeated administration records while keeping editing clear, accessible, and safe. Preserve full image meaning instead of cropping illustrations, screenshots, badges, and question assets.

## Acceptance criteria

- [x] Desktop sidebar and main content scroll independently inside the viewport.
- [x] Repeated records show compact summaries and reveal full forms only when opened.
- [x] Record summaries keep status and key metadata visible without opening the form.
- [x] Non-cover image previews use contained fitting; cover images keep intentional cropping.
- [x] Wide desktop screens use additional columns where scanning benefits from them.
- [x] Feedback screenshots display the complete captured viewport.
- [x] Interactive targets retain usable keyboard focus and practical target sizes.
- [x] Existing roles, form behavior, API boundaries, and child-safety rules remain unchanged.
- [x] Formatting, lint, typecheck, unit tests, build, and targeted browser checks are completed.
