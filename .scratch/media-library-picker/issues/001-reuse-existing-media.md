# Tái sử dụng tư liệu trong biểu mẫu

Các biểu mẫu hiện chỉ mở file picker của hệ điều hành. Điều này khiến người quản trị tải lại cùng một ảnh nhiều lần, tạo bản ghi trùng và tốn dung lượng lưu trữ.

Bổ sung một media picker dùng chung cho toàn bộ `MediaUploadField`, giữ upload mới như lựa chọn thứ hai.
