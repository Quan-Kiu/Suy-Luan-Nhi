# Mission editor independent scrolling

## Goal

Keep the desktop mission editor inside the admin viewport while allowing the editing form and child preview to scroll independently.

## Acceptance criteria

- At desktop widths, the left editing region has its own vertical scrollbar.
- At desktop widths, the right preview region has its own vertical scrollbar.
- Scrolling either region does not move the other region or the admin page container.
- Tablet and mobile layouts continue using the existing single-column page scroll.
- Both scroll regions remain keyboard focusable and labelled for assistive technology.
