# Admin UX refresh

## Objective

Redesign the administration experience for non-technical content staff while preserving role-based access, child-safety review, structured persistence, and advanced operational controls.

## Acceptance criteria

- [x] Navigation is grouped by user task and filtered by role.
- [x] Dashboard prioritizes actionable work rather than raw system metrics.
- [x] Mission statuses, roles, question types, and safety criteria use plain Vietnamese labels.
- [x] Mission questions are edited through structured controls instead of raw JSON.
- [x] Slugs, URLs, metadata, and configuration details are secondary or collapsed.
- [x] Review and publication consequences are explained in context.
- [x] Core admin pages have consistent headings and descriptions.
- [x] Formatting, lint, typecheck, unit, integration, build, and targeted browser tests pass.
