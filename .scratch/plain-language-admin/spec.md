# Plain-language admin UX

## Goal

Make the admin workspace understandable to ordinary content staff without requiring knowledge of code, database fields, CMS terminology, or internal product names.

## Research principles

- Organize screens around user tasks and locations, not implementation keys.
- Keep forms vertical, with visible labels and short contextual instructions.
- Describe errors in plain language and explain how to fix them.
- Keep technical identifiers behind progressive disclosure.
- Preserve keyboard, screen-reader, mobile, and non-drag alternatives.

## Initial scope

- Rebuild the interface-copy manager as a plain-language Content Studio.
- Add friendly labels for areas, sections, and content purposes.
- Add default/current comparison and reset-to-default workflow.
- Simplify admin navigation labels and descriptions.
- Add loading skeleton, error recovery, empty guidance, and read-only explanation.
- Preserve typed API adapters, TanStack Query, React Hook Form, cache invalidation, and audit logs.
